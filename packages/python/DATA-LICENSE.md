# Data license

The files in `data/` (and the copies shipped in the npm and Python packages)
are derived from OpenStreetMap and are licensed under the
**Open Database License (ODbL) 1.0**: <https://opendatacommons.org/licenses/odbl/1-0/>.

Attribution: **© OpenStreetMap contributors**, <https://www.openstreetmap.org/copyright>

In short, you may use, share and adapt the data, provided that you:
- **attribute** OpenStreetMap contributors in any public use,
- **share alike**: a public adapted database must also be offered under the ODbL,
- **keep it open**: do not add technical restrictions without also offering an unrestricted version.

A map or app that only *uses* the data (a "produced work") can be under any
licence, as long as it carries the attribution.

The build scripts and package code are MIT licensed (see `LICENSE`).
